# Проверка ZelenkaMusic 0.1.2

Проверено 15 ноября 2026 года на Windows, Rust 1.100.0 и MSVC.

## Исправление восстановления окна

В программном рендерере Slint 1.9.2 сохранённый DIB и отображаемая поверхность Windows обрабатывались как одна область. При восстановлении окна Windows может потребовать обновить всю клиентскую поверхность, хотя буфер Slint остаётся действительным. Раньше в окно копировались только изменившиеся участки, а при неизменном интерфейсе вывод вообще пропускался. softbuffer затем валидировал всю клиентскую область, оставляя неподвижные края без восстановления.

В `vendor/i-slint-backend-winit/renderer/sw.rs` на Windows теперь выводится весь сохранённый буфер при каждом запросе отрисовки, включая запросы без изменений сцены. Частичная отрисовка внутри буфера сохранена. Исправление подключено через Cargo patch и не зависит от локального кэша зависимостей. Снег и аудио не пересоздаются при обновлении поверхности.

## Выполненные проверки

- `cargo test --offline --all-targets` — успешно: пять модульных тестов, проверка ползунков/снега и две новые регрессионные проверки. Тест реального аудио выполнен отдельно.
- `cargo test --offline --bin zelenka-music real_ui_and_audio_smoke -- --ignored --nocapture` — успешно. Проверены MP3/FLAC через реальный CPAL-выход Windows при нулевой громкости, перемотка, пауза, переходы в конце трека, воспроизведение при переключении страниц, плейлисты, сохранение снега, повреждённый файл и отсутствующая папка музыки.
- `cargo clippy --offline --all-targets -- -D warnings` — успешно.
- Всего прошло **9 тестов**.
- `retained_image_restores_exposed_edges_and_unchanged_scene` восстановил **48 поверхностей** настоящего интерфейса со снегом и без него в размерах 1120 × 820, 940 × 760 и 1280 × 900. Среди них 21 кадр без изменений сцены и 21 кадр с частичными изменениями. Проверяются все пиксели, включая края.
- `native_gdi_restores_unchanged_surface` выполнил **12 циклов** восстановления пикселей на настоящих поверхностях Win32 GDI через BitBlt при пустой области изменений сцены.
- При временном возврате прежнего выбора области вывода обе регрессионные проверки упали. После возвращения исправления прошли.
- Существующая проверка ползунков выполнила клики и 200 событий движения мыши, проверила одну команду перемотки при отпускании, изменение громкости во время движения и работу после изменения размера окна. Проверка частичной отрисовки снега на всех трёх страницах в одном и двух буферах также прошла.

- Оптимизированная сборка Windows EXE и установщик 0.1.2 успешно собраны. Версия в ресурсах EXE — 0.1.2.
- SHA-256 корневого EXE, release EXE, переносимой версии, извлечённого установщика и распакованного ZIP совпадает: `A9658A236254EFE2E43DB0F505B4E4922D9376BCA5EF71CAB7267F27A420CAF7`.
- Проверено извлечение установщика внутри `target/verification`, без установки в пользовательский профиль. У `Uninstall.ps1` сохранён UTF-8 BOM для Windows PowerShell 5.

## Границы проверки

Потеря отображаемой поверхности в регрессионных тестах моделируется очисткой назначения при сохранении буфера интерфейса. Тест GDI использует настоящий BitBlt, но видимое сворачивание/восстановление окна и пиксели DWM на рабочем столе не проверены автоматически. Отдельная проверка на Windows 10 и отключение аудиоустройства также не выполнялись.
